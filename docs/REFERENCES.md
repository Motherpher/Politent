# Politent reference policy

A method is called an **established Politent component** only when:

1. its role is traceable to a primary, peer-reviewed or authoritative source;
2. Politent's use matches what the method actually estimates;
3. methodological limitations are documented;
4. synthetic Politent constructs are labelled as synthetic;
5. data-source time/geographic coverage is explicit;
6. later implementation work does not silently redefine the cited concept.

The registry should expand as implementation proceeds, but canonical definitions require versioned changes.
